# Trigo

A front-end Flutter demo for local e-rickshaw rides and parcel delivery. All locations, drivers, payments, and trip details are intentionally fake.

## Run

1. Install Flutter from [flutter.dev](https://flutter.dev).
2. From this folder run `flutter create . --platforms=android,ios,web` once to generate the native platform folders.
3. Run `flutter pub get`, then `flutter run`.

## Included demo flows

- Book an e-rickshaw by choosing a pickup and destination.
- Choose a local parcel delivery vehicle and send an item.
- Follow a simulated active ride and driver details.
- Browse recent rides and parcels in the activity tab.
